# SiGe selective etching

Selective isotropic etching of a SiGe stack with CF4/O2 chemistry.

## Etching

Run from the repository root:

```bash
cd docs/examples/SiGeSelectiveEtching && uv run python SiGeEtching.py -D 2
```
